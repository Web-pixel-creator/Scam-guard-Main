# Ishonch Guard

Ishonch Guard помогает жителям Узбекистана разобраться в подозрительном звонке, сообщении или просьбе перевести деньги. Можно описать ситуацию в [Telegram](https://t.me/scamguard_bot) или на сайте. Помощник отвечает на русском, узбекском и английском: что именно насторожило, чего пока нельзя установить и что сделать дальше.

В Telegram можно задать вопрос в личном чате или вызвать бота из другой переписки в режиме Inline. На сайте есть проверка, справочник официальных контактов, помощь после инцидента и форма жалобы. **Доступность сервиса:** [последняя проверка](ai_docs/CURRENT_STATE.md).

## Что означает ответ

Правила оценивают признаки риска, а не выносят приговор человеку. Отсутствие признаков не означает «безопасно». Жалоба влияет на публичную репутацию только после модерации. ИИ может объяснить результат, но не определяет уровень риска. Не отправляйте пароли, коды подтверждения или данные карты. При включённом распознавании изображение или голос могут обрабатываться внешним провайдером.

## Локальный запуск

Понадобится Bun (версия указана в [CI](.github/workflows/ci.yml)). Из корня репозитория:

```sh
bun install --frozen-lockfile
test -e .env || cp .env.example .env
bun run dev
```

В PowerShell для создания файла используйте `if (!(Test-Path .env)) { Copy-Item .env.example .env }`. Для интеграций используйте тестовое окружение, не production-секреты. Основные проверки: `bun run lint`, `bunx tsc --noEmit`, `bun run test:run`, `bun run build`.
